# VOK Blog Support

[blog.vokzxcnm.com](https://blog.vokzxcnm.com)의 콘텐츠 문의, 정정 요청, 사이트 오류 제보와 개선 제안을 받는 공개 지원 저장소입니다. 운영자는 **VOKZXCNM**입니다.

블로그와 연도별 아카이브의 문의를 이 저장소에서 함께 관리합니다. 사이트 소스 코드나 리포트 원본을 배포하는 저장소는 아닙니다.

## 문의 접수

먼저 [기존 이슈](https://github.com/vokzxcnm/blog.vokzxcnm.com-support/issues)를 검색해 같은 내용이 있는지 확인해 주세요. 같은 문제가 있다면 해당 이슈에 추가 정보를 남겨 주세요.

새로운 문의는 [이슈 작성](https://github.com/vokzxcnm/blog.vokzxcnm.com-support/issues/new)으로 접수할 수 있습니다. GitHub 계정이 필요합니다.

| 유형 | 함께 알려주실 내용 |
| --- | --- |
| 콘텐츠 문의·정정 요청 | 블로그와 연도, 리포트 URL, 해당 문장·수치, 정정 근거와 출처 |
| 사이트 오류 | 발생 페이지 URL, 재현 순서, 기대한 결과와 실제 결과, 기기·브라우저 |
| 개선 제안 | 불편한 점, 제안하는 변경, 도움이 되는 이용 상황 |

제목에는 `[정정]`, `[오류]`, `[제안]`, `[문의]` 중 알맞은 구분을 붙이면 확인하기 쉽습니다.

예: `[정정] US Market Brief 2026 — 리포트 내 지수 등락률 확인 요청`

아래 양식을 복사해 필요한 항목을 채워 주세요. 확인되지 않은 내용은 추측해서 작성하지 않아도 됩니다.

```text
문의 유형:
블로그 / 연도:
페이지 URL:

문의 또는 문제 내용:

근거·출처 / 재현 순서:

기대한 결과 또는 개선 제안:

기기·브라우저 (사이트 오류인 경우):
```

## 공개 범위와 개인정보

**이슈와 댓글, 첨부파일은 공개됩니다.** 비밀번호, 인증 코드, API 키, 연락처, 계좌 정보 등 개인정보나 비공개 자료를 올리지 마세요. 스크린샷에도 이러한 정보가 포함되지 않도록 확인해 주세요.

개인정보 관련 문의는 공개 이슈 대신 **[vokzxcnm.app@gmail.com](mailto:vokzxcnm.app@gmail.com)**으로 보내 주세요. 일반 콘텐츠 문의와 오류 제보는 GitHub Issues를 이용해 주세요.

## 확인과 정정

- 접수된 내용은 제공된 URL과 근거를 바탕으로 확인하며, 필요한 경우 추가 정보를 요청합니다.
- 시장 리포트의 날짜는 시장 기준일 또는 대상 기간일 수 있습니다. 수치를 비교할 때는 기준 시점, 단위, 출처와 계산 방식을 함께 확인해 주세요.
- 내용의 의미가 달라지는 정정은 해당 리포트에 정정 날짜와 변경 내용을 남기는 것을 원칙으로 합니다.
- 처리 결과는 이슈에 안내하고, 해결되거나 검토가 마무리된 이슈는 닫습니다. 중복 요청은 기존 이슈로 연결할 수 있습니다.
- 답변이나 수정 완료 시점을 보장하지는 않습니다. 추가 정보가 있다면 같은 이슈에 이어서 남겨 주세요.

이 저장소는 블로그 운영과 콘텐츠 개선을 위한 공간입니다. 개인별 투자 상담이나 매매 판단 요청은 다루지 않습니다. 서로를 존중하며 문제와 근거를 중심으로 작성해 주세요.
